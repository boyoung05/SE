# **1\. 서론**

## **1.1 문서의 목적 및 범위**

본 문서의 목적은 웰폰키즈 시스템의 주요 기능이 요구사항에 맞게 정상적으로 동작하는지 확인하기 위해 수행한 테스트의 기준, 범위, 테스트 케이스 및 결과를 정리하는 것을 목표로 한다. 

테스트 범위는 사용자 회원가입, 로그인, 보호자/아동 정보 관리, 기기 연동, 위치 확인, 알림 기능 등 웰폰키즈 서비스의 핵심 기능을 포함한다.

## **1.2 프로젝트 개요**

웰폰키즈는 보호자가 아동의 스마트폰 사용 상태를 확인하고, 주요 알림 등을 관리할 수 있도록 지원하는 아동 안전 관리 서비스이다. 사용자는 보호자 계정으로 로그인하여 아동 정보를 등록하고, 기기 연동 상태, 알림 내역 등을 확인할 수 있다.   
이 서비스는 아동의 스마트폰 과의존을 단순히 차단하는 것이 아니라, 통제 중심 서비스에서 벗어나 부모와 함께 건강한 디지털 생활습관을 형성하도록 돕는다.   
따라서 이 서비스는 제한보다 관계 개선과 습관 형성에 초점을 둔다. 

## **1.3 용어 정의**

본 문서의 이해를 돕기 위해 사용된 용어 및 약어를 설명하고 정의합니다,

| 용어 | 설명 |
| ----- | :---: |
| 스마트폰 과의존 | 스마트폰 사용 조절이 어려워 일상생활, 학습, 수면, 대인관계 등에 부정적 영향을 받는 상태 |
| 코칭 | 강제 차단이 아니라 건강한 사용 습관 형성을 돕기 위해 안내하고 지도하는 방식 |

# **3\. 테스트 케이스**

## **3.1 테스트 케이스 선정**

테스트 케이스는 본문 2.2의 테스트 항목에 따라 선정되었으며, 웰폰키즈 시스템의 주요 기능이 요구사항에 맞게 정상적으로 동작하는지 확인하는 것을 목적으로 한다.  
본 테스트는 사용자의 관점에서 기능 수행 결과를 확인하는 블랙박스 테스트를 중심으로 진행하며 본문 3.3에서 테스트 케이스 목록을 나열한다.  
각 테스트 케이스는 정상 입력뿐만 아니라 잘못된 입력, 필수값 누락, 인증되지 않은 접근 등 비정상 상황을 포함하여 시스템의 안정성과 예외 처리 여부를 함께 확인할 수 있도록 구성하였다.

## **3.2 테스트 케이스 유형**

테스트 케이스 유형은 다음과 같다.

- 회원가입, 로그인, 아동 등록, 기기 연동 기능을 수행하기 위한 문자열 및 정보 입력 테스트 케이스  
- 안드로이드 기반 시스템의 화면 이동, 버튼 클릭, 기능 실행 여부를 확인하기 위한 동작 테스트 케이스  
- 보호자 계정과 아동 정보, 아동 기기 정보 간의 연동 여부를 확인하기 위한 데이터 입력 및 확인 테스트 케이스  
- 미션 생성, 수행, 완료 여부 확인을 위한 서비스 흐름 테스트 케이스  
- 스마트폰 사용 기록과 미션 수행 결과를 기반으로 AI 리포트가 생성되는지 확인하기 위한 결과 확인 테스트 케이스  
- 미션 및 휴대전화 사용 관련 알림이 정상적으로 표시되는지 확인하기 위한 알림 테스트 케이스  
- 인증되지 않은 사용자의 접근 제한 여부를 확인하기 위한 보안 테스트 케이스
